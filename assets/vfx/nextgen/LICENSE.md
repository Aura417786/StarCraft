# Original v35 effect assets

The water, magma and void atlases were authored specifically for Star Breaker
using the project's Blender procedural scene script. They contain no pixels
copied from the supplied reference screenshots or third-party artwork.

Authoring: tools/art/author_nextgen_vfx.py
Packing and alpha/animation checks: tools/art/pack_nextgen_vfx.py
Hashes and frame layout: manifest.json

They follow the repository's asset licensing terms. Blender-generated output
does not require distributing the Blender application with the game.

## v35.1 black-hole-accretion.png

Original generated artwork created specifically for this project on 2026-11-17
using the built-in image generation tool. The user's purple/blue spiral
reference guided composition, color and surface detail; no source screenshot
pixels or browser UI are distributed as game art. Two generation/edit prompts
and original outputs are retained in AI_Development/Art/blackhole-v35-1.
1254 x 1254 RGBA PNG; 1,399,515 bytes. Runtime shader animation is original
project code in blackhole-surface.js; no new engine or external CDN dependency.

## v36 dimensional collapse

The twelve phase keys in `void-inclined-horizon.webp` project the original
`black-hole-accretion.png` material onto the corona, counterimage and spiral
folds. The two incoming sheets, opaque horizon and luminous rim were authored
for Star Breaker. `void-collapse-front.webp` contains the independently clipped
contact annulus. `void-shear.webp` contains the tileable folded ray material.
All three are rebuilt by `tools/art/bake_inclined_horizon.py` using NumPy and
Pillow. No external reference image is included in the game.

## v36 material assets

`tidal-breaker.webp` is a transparent sequence made for Star Breaker. Four
illustrated wave poses run from swell through overturn to surf. They were
authored with the built-in image generation tool and kept in
`tools/art/sources/tidal-breaker-poses.webp`. Running
`python tools/art/bake_tidal_breaker.py` rebuilds the sixteen-frame atlas
using motion estimation in premultiplied color. The boss and the player's
borrowed tide use this atlas with the same refraction and spray.
`void-inclined-horizon.webp` is a project-authored animation atlas. Its bake
script is `tools/art/bake_inclined_horizon.py`. The organ and ejected-material
atlases are generated by `tools/art/bake_boss_organs.py` and
`tools/art/bake_boss_ejecta.py`. They follow the repository's asset terms.

The ten isolated organs in `living-organs.webp` were originally generated for Star Breaker with OpenAI ImageGen. Each cell has a transparent gutter. The game animates these materials on grasping, refracting, feeding, and discharging structures.

The ten isolated spell materials in `spell-matter.webp` were generated specifically for Star Breaker using OpenAI ImageGen. The ivory, magma, silk, chitin, crystal, plasma, fungal, accretion, neural and fusion cutouts share one alpha atlas. Their movement, light, size and attachment to attacks are authored per boss in the runtime.
