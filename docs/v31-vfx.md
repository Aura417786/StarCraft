# v31 异形入场与战斗特效

在单首领练习里选择不同 Boss，可以快速比较怒吼、入场和招式。战役中也使用同一套效果。异形信号出现后，首领名和抵达倒计时会留在战场一侧，异象在首领将出现的位置成形。正常流程中，专属怒吼约在出场前 1.8 秒播放。关闭声音时仍可根据画面判断抵达时间。

| 场景 | 画面 |
| --- | --- |
| 十一只 Boss | 卷潮、骨脊、熔流、裂隙蛛网、合拢双螯、棱镜翅、编织洋流、孢子花、黑洞吸积盘、神经分枝、三重交汇光环 |
| 飞行与补给 | 分层尘埃和星光、淡色弧线、贴着机身的发动机尾流和带符号的能量晶体 |
| 攻防 | 主炮及敌弹尾丝、发射光、激光锁定、精英地雷和护卫盾、玩家护盾边缘与弹反冲击 |
| 战机技能 | 赤焰炮内的交错流束、苍电导弹的蓝色尾迹、曜金弹幕的金色波前、烬火印记、冰霜折射和回溯环 |
| Boss 战 | 专属招式和绝招的预警、活跃判定和退场，破壳、终局变形、死亡碎片和爆炸 |
| 航行事件 | 引力潮、弹射轨迹和返航星门的附着光效 |

实线弹头与危险边界仍用于判断碰撞。粒子使用确定性的视觉种子，与战斗随机数分开。画质档位调整装饰层和粒子密度。减少动态效果会收敛装饰运动，保留倒计时和危险轮廓。

视觉参考是短片的干涉环、星云、熔融纹理和黑洞吸积盘。参考画面用来确定光的层次与造型，游戏中的效果按实际战斗位置和事件时间绘制。[《万物》公开短片](https://www.bilibili.com/video/BV1BxWu6SESe)

采用 combat VFX 技能的视觉与机制分离及运行验收方法、game-feel 的接触与重击反馈分层、Three.js 技能的造型优先和浏览器性能预算。Phaser 和 Effekseer 技能已安装供后续选择，本轮运行时沿用项目的 Canvas 和 Three.js。[Combat VFX](https://github.com/John-Sun27/creating-game-combat-vfx) · [Game Feel](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/tree/main/skills/disciplines/game-feel) · [Three.js Graphics Builder](https://github.com/majidmanzarpour/threejs-game-skills/tree/main/skills/threejs-aaa-graphics-builder)

复测时请留意三件事。

1. 开声音挑战不同 Boss，检查怒吼先于现身，且暂停、调整窗口和重试时不会出现同一段声音叠播。
2. 分别使用三架战机的空格大招与三条 F 进化技能。普通战中观察弹道、补给、护盾和命中是否容易辨认。Boss 战中检查预警边界、实弹和安全通道。
3. 用高低画质与减少动态效果对照相同招式，记录窗口尺寸、帧时间和会遮挡危险的瞬间。
