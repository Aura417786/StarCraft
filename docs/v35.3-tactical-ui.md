# v35.3 沉浸式界面

以开放式仪表、直接叠在画面上的技能符号和留白为方向。参考《地平线》将关键读数聚在屏幕边缘的做法，以及《黑神话：悟空》用名称与细条呈现 Boss 状态、用技能符号标示状态的做法。星际突围用米白与暖金建立文字层级，用青色指示安全路线，并保留战机各自的能量色。[地平线 5 官方实机](https://www.youtube.com/watch?v=CPgUk3NZcbI) · [地平线 6 官方实机](https://www.youtube.com/watch?v=H1qlPZMfmiU) · [黑神话：悟空实机与宣传素材](https://store.steampowered.com/app/2358720/Black_Myth_Wukong/)

- **战斗。** 生命、武器、圆形大招表和护盾符号贴边悬浮，读数通过淡暗角保持可读。Boss 名称独立居中，金色护壳和米白核心使用双轨。徽记区分首领，拖尾显示刚损失的血量。
- **攻击预警。** 封域提示用独立文字和数字倒计时。安全通路用渐隐光迹和箭头导向，危险边缘用元素色光点和渐变显示，仍沿用原有空间判定。
- **交互。** 暂停和退出确认在压暗的战斗背景上以有间距的菜单显示。设置用左侧分类和右侧选项，主音量、音乐和音效可独立调整。设置可在重载后恢复。
- **战前与结算。** 机库用开放式菜单衬托战机，出击配置有基于原始属性的四维雷达。改装、战役进度、徽章、连战与每日挑战沿用档案数据。战报根据成功或失败改变层级与按钮，飞行手册和训练提示沿用同一字体与配色。

在 Chrome 下检查 1920×1080、1440×900、1280×720、640×360、390×844 和 2560×1080。小窗折叠次要说明，较长的机库配置可滚动。浏览器控制夹具验证了物理键盘事件与模拟标准手柄输入。技能特效、存档和战斗结果可使用原测试工具复查。

本机独立试玩包按 `v35.3-cinematic-ui` 标签导出。
