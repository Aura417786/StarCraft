# v29：首领连携与元素绝招

这次按用户补充要求把原提示词的三批连续完成、统一验收。基础点是 v28 的 `f71e0c5`，本地检查点为 `checkpoint/v28-before-pressure`。v28 的正式文件、历史构建和版本标签保留。

## 战斗结构

十只常规 Boss 交替使用两组有明确联系的攻势。第一段确定危险区或逃生位置，第二段从这一实际几何位置继承目标；日志记录源坐标、目标坐标、起止时间和重叠长度。第二段有独立的音色和颜色。所有预警至少 0.9 秒，普通收招至少 0.8 秒。第十一只合体保留已有拆肢、走廊与终局流程。

| Boss | 连携一 | 连携二 | 专属绝招及实际机制 |
|---|---|---|---|
| 渊潮母体 | 浪墙缺口 → 涡心牵引 | 回涡 → 水压环 | 渊潮合涌：两面相向水墙、移动泄压缝和水流推力 |
| 骨冠猎兽 | 骨笼 → 落冠 | 闭合颚环 → 斜向骨矛 | 万骨王冠：旋转放射骨刺与扩散骨环 |
| 灼核吞星兽 | 石脊遮蔽 → 背面回火 | 炉口喷流 → 熔环 | 吞星熔裂：上下侵入的熔河与分段喷发的熔核 |
| 裂隙织母 | 蛛网减速 → 丝环收紧 | 织线 → 反向剪切 | 万维天罗：可射断节点的丝笼与向中心收束的丝线 |
| 锁脉巨螯 | 钳口 → 竖向断层 | 锚点牵引 → 震荡环 | 双锚碎界：从右侧推进的上下巨钳及钳口内的交叉冲击 |
| 星尘镜魟 | 反射盾与光线 → 双向夹击 | 假影 → 汇聚镜光 | 万镜归光：可打碎的三角棱镜阵列，反射路径和扫射束 |
| 沉渊震鳗 | 尾电极 → 电潮 | 电潮缺口 → 逆向电弧 | 环渊雷狱：两重扩散电网与旋转径向电弧 |
| 裂梦孢皇 | 孢巢 → 孢粉环 | 寄生涡 → 后方孢浪 | 梦魇孵界：可击破的孢囊分时膨胀，活孢囊形成危险云团 |
| 维度噬口 | 引力场 → 裂缝 | 旋流 → 收缩虚空环 | 无光坍缩：牵引、收缩环、中心坍缩及旋转空间裂线 |
| 无昼神经王 | 按序节点 → 电潮 | 神经环 → 反向扫描 | 神经寂灭：可切断节点按顺序激活纵横电路 |

绝招的最终冲击可以封闭所有普通移动路线，需在倒计时结束前使用护盾。没有足够护盾储备时会给一次应急充能，并显示提示。禁盾挑战改为保留明显安全通路；背景火力也遵守该通路。全屏强制防御是公开的时机考验，不依赖隐藏碰撞。每次绝招还包含各自的空间机制，不能用共同终结冲击代替其独立攻击。

常驻弹流是确定性的缓慢移动阵列，所有列共用一个移动缺口，避免不同列交叉造成意外封死。周期护壳将伤害乘以 0.15，结束有局部破裂反馈。原有 Boss 入场战力快照、血量公式与存档结构不变。

## 画面实现与参考

使用仓库已有的 [Create Game VFX](../.agents/skills/create-game-vfx/SKILL.md) 流程：先定义触发、预警、作用范围、反馈和清理，再制作效果；特效不参与伤害判定。参考 [Game Science 的 Unreal Engine 访谈](https://www.unrealengine.com/developer-interviews/black-myth-wukong-wows-with-ue5-early-access-visuals?lang=en-US) 的材质、光照和整体环境一致性方向，以及 [Making of Furi](https://store.steampowered.com/app/629150/Making_of_Furi/) 所强调的战斗与美术协同。没有引入这些商业游戏的资源，也不宣称本项目已达到其成品画质。

- `boss-pressure.js` 定义连携、绝招几何、实际伤害、节点和推力。
- `boss-pressure-copy.js` 保存双语行动提示和专属技能名称。
- `boss-ultimate-art.js` 读取同一份几何，按水、骨、岩浆、丝、甲壳、镜面、电、孢、虚空、神经分别绘制主体。
- `boss-pressure-art.js` 管理聚能、材质余烬、镜头推拉、变形、护壳破裂和低画质降级。
- `boss-vfx-materials.js` 缓存确定性的多层噪声密度及法线光照纹理；不使用游戏随机数，不在每帧重建纹理。
- 危险边界使用单独的低饱和轮廓，放在主体特效之后绘制。禁盾通道同时裁切危险视觉与碰撞范围。
- 电网的同宽弧段合并成多子路径提交，保留每一段的采样和危险范围；虚空吸积弧只有在描边及抗锯齿余量都完全落入裁剪内孔时才跳过。减少无效绘制，不删除攻击几何。合批接缝的重复叠加亮度可能略减，最终实机复核另列。

## 验证口径

原 `boss-scaling.cjs --strict` 门槛保持不变。九场沿用种子 4225、三种原装备、三个代表 Boss、同一自动驾驶。计时夹具仍使用 14 生命，用于覆盖完整本体和终局；它不是普通三生命玩家胜率。

`pressure.cjs` 记录原始连携事件、十种绝招的真实判定、节点破坏、护盾免伤、禁盾通道、暂停和缩放。安全输出同时报告近距风险启发式、真实无防御连续输出窗口和静止输出窗口。新旧版本按同一测量法比较，不把旧报告估算的“60%”当精确基线，不把“屏幕有弹”当作“不能输出”。

实机截图及短片使用真实 RAF 和正式渲染。为了逐一展示绝招，视觉场景关闭玩家主炮并延长受伤保护；这些样片明确标注为定点视觉检查，不能作为自然通关证据。正式平衡和碰撞检查使用未替换的伤害逻辑。性能记录包含机器、Chrome、分辨率、画质、原始 RAF 和 JS 帧采样，不能代表所有设备。

旧单元测试中依赖“第一招必定是若干普通弹丸”“所有 Boss 每招预警至少 1.4 秒”“高装备一定继续缩短已达下限的间隔”的断言，迁移为本版真实连携和 0.9/0.8 秒契约。保留了合体逃生、投射物碰撞、暂停、全屏缩放、三机、存档和音频的实质回归检查。

最终数值、未达标项、构建哈希及截图位置见本轮发布报告；此设计说明不代替运行结果。
