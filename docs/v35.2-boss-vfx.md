活动阶段的攻击由各材质绘制，虚线和边界主要用于预警。无盾封域由封域预警负责标示固定缺口，攻击与缺口交界的光效限制在危险侧。调整分辨率时丢弃已经缓存的预警形状，按变换后的位置重建。低画质精简粒子和纹理层，减弱动态时冻结装饰流动。水、熔岩、孢尘的预加载利用已有的 Boss 进场准备时机。

使用项目原有 Canvas 2D、Three.js 首领模型和 v35 的材质资产，新增的特效材质由 JavaScript 生成并缓存。运行代码通过 Git 进入独立构建，玩法节点、碰撞和时间由原有规则计算。

## 验证口径

- Chrome 渲染按 11 只首领、高画质和低画质减弱动态、两条普通连携、两种绝招护盾条件取样。共 88 个场景和 924 帧，覆盖起手、生效、尾帧及封域冲击，页面和渲染均无异常。
- `tools/testkit/nextgen-vfx.cjs` 的 24 项原有像素遮罩检查、18 张分阶段实机图和资源加载检查通过。
- `tools/testkit/nextgen-combat.cjs` 覆盖 55 个封域场景、三个视口的 132 组本体连携和 33 个终局序列。实测数据与冻结的 v35.1 逐字段相同，源文件指纹随渲染代码变化。
- 22 张高清图从正式运行时取样。部分招式的截取时刻与 v35.1 不同，以展示已经生效的衔接攻击。上述检查属于固定场景测试，不能代替完整手操通关。

版本标签 `v35.2-boss-vfx`。本机的版本 ZIP、逐文件清单、SHA-256 和启动说明位于对应 `AI_Development/Builds` 目录。
