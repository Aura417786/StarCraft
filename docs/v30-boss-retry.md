# v30 · Boss 战回溯

本轮增加当前 Boss 的入场检查点，方便玩家在阵亡后继续学习同一场战斗。本文件说明功能语义和待执行的手工验收步骤；不代表这些步骤已全部通过，也不代表公开试玩站已部署此版本。

本轮也重做了命中反馈、三档难度和互斥进化，见 [v30 战斗与进化说明](v30-combat-evolution.md)。其中 F 键的「时隙回溯」是活着时使用的短时技能，与本文件描述的死亡后重试按钮分别处理。

## 玩家如何使用

1. 正常开始战役、首领连战、练习或每日挑战。每周连战使用相同规则。
2. Boss 出现时，游戏在内存中记录本场入场状态。
3. 在这只 Boss 的普通、狂暴或最终形态中阵亡后，结束画面显示「从本场 Boss 重新挑战」（英文为 `Retry this boss`，按钮 ID 为 `boss-retry-button`）。
4. 点击按钮，回到该 Boss 开始出现的时刻，再从它的初始形态战斗。

「重新开始」仍然从所选模式的起点开新局。胜利、主动退出和没有 Boss 在场时的阵亡不提供本场回溯。

## 恢复范围

回溯恢复入场时的战机型号、装备数值、射击姿态、进化选择、生命及生命上限、大招与护盾储备、连击与暴走状态、战斗时间和局内进度。不能把失败后消耗殆尽的技能或零生命带回开场，也不能每次重试都凭空补满原本没有的储备。

新进化使用单一路线与等级；死亡回溯也应恢复入场时的路线、等级与技能冷却，不能变成重新三选一。原有三架战机的大招和通用护盾继续存在。

Boss 从自己的开场重新出现，拥有初始生命值，不保留失败时的破壳、终局、攻击进度或旧攻击判定。上一轮的弹幕、技能实体和死亡演出不能继续伤害新的战机。

连续重试同一只 Boss 时，始终使用第一次进入这场战斗的检查点。成功击破后旧检查点失效；下一只 Boss 出现时创建新检查点。

检查点只属于当前页面的当前航次，不是跨会话存档。刷新、关闭页面、返回菜单或开始新局会清除它。已有浏览器存档中的改装、偏好和历史纪录不因此删除。

## 成绩与奖励

第一次失败沿用原有结算。选择回溯后，整局标记为重试航次：仍可继续通关，获得后续新击破的战役 Boss 解锁和击破点数，但不再登记本局成绩、速通、无伤或其他成就，也不重复累计失败前已经结算的击杀与 Boss 纪录。

以上限制同样适用于每日、每周及首领连战，避免用回退后的时间或生命刷新正式纪录。练习模式也允许重试，但不会因此产生正式战役奖励。回溯不会撤销之前已经获得的永久解锁或点数；同一个 Boss 的多次失败本身不发奖励。

## 手工验收清单

验收时记录版本、模式、战机、Boss、浏览器与分辨率；保存入场及回溯后的截图。不得将尚未执行的步骤标注为通过。

| 场景 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 基本回溯 | 进入首领战，记录生命、储能、装备；阵亡后点击回溯 | 同一只 Boss 从开场出现，所记数值回到入场值 |
| 三架战机 | 分别选择赤焰、苍电、曜金重复基本流程 | 型号、大招类型和该机独有资源不串用 |
| 非初始配置 | 以高于初始的生命上限、缺血、部分储能、已有进化进入 Boss | 恢复入场的实际数值，既不变初始配置，也不免费补满 |
| 连击与时间 | 带连击或暴走进入 Boss，失败后回溯 | 连击、暴走剩余状态和战斗时间恢复到入场时 |
| 最终形态阵亡 | 将 Boss 打到独立终局阶段后阵亡 | 从该 Boss 初始形态重打，不直接从终局开始 |
| 连续失败 | 回溯后再次消耗资源、阵亡并回溯 | 两次回溯起点一致，第一次失败不会污染原检查点 |
| 下一个 Boss | 击败并推进至下一只，再阵亡 | 回溯目标更新为新 Boss，使用新的入场配置 |
| 非适用结算 | 分别在小怪阶段阵亡、主动退出、正常获胜 | 不出现可用的旧 Boss 回溯按钮 |
| 旧攻击清理 | 在密集弹幕、护盾或大招效果中阵亡后回溯 | 无前一次战斗遗留的命中、声音循环或死亡演出 |
| 计分边界 | 记录档案统计，回溯并继续获胜；覆盖每日、每周、连战 | 不刷新正式成绩、速通/无伤等成就，不重复累计已结算记录 |
| 战役奖励 | 回溯后第一次击破当前 Boss，再推进 | 新解锁和击破点数正常获得；仅失败重试不加点数 |
| 页面生命周期 | 分别刷新、关闭重开、返回菜单、重新开始 | 旧检查点不能跨页面或跨新局恢复 |
| 中英文与控制 | 切换语言，用鼠标与键盘聚焦按钮；恢复后移动、开盾、开大 | 文案正确，恢复键盘焦点，无按键粘住；手柄有硬件时另测 |
| 窗口变化 | 死亡后改变窗口或切换全屏，再点击回溯 | 战机与 Boss 留在可用区域，布局和危险判定正常 |
