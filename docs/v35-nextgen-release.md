# v35：元素战斗与视听升级

v35 在 v34 的 Canvas 2D 战场与 Three.js Boss 基础上升级特效、战斗和音频，保留 11 只 Boss、三架战机、成长路线、模式、中英文与存档兼容路径。

## 设计与实现

危险区的几何判定继续作为画面的依据。Blender 制作的水、熔岩、虚空图集与实时材质层结合，补充波浪截面、泡沫、岩壳、熔沟、吸积带及局部背景折射。骨、丝、甲壳、晶体、电流、孢子和神经使用不同轮廓。最后一轮收尾改成圆卷水端和不规则岩岸，移除重复大图集；熔沟使用一次缓存的冷热结壳纹理，岩面使用连续明暗。在原遮罩内保留浅水纹与细热纹，使整个危险范围仍可辨认。

11 只 Boss 各有两套三段组合，将铺场、截击、惩罚和恢复连接起来，低生命与终局继续改变压力。位置在预警时锁定，Boss 通用弹丸阵列退出这套流程。有盾和无盾分支保留明确解法，不免费补盾；普通敌人弹仍可触发完美格挡返还。战机以赤焰重炮、苍电追踪和曜金覆盖区分技能表现。

音频新增 66 段 Boss 材质声、33 段战机事件声、6 条音乐分轨，采用原创离线合成与 MIDI 演奏。音乐在机库、精英、低生命和 Boss 阶段间分层变化，预警优先压低背景声音。新资产带可重建脚本、清单与许可证，未迁移引擎或使用付费生成服务。

## 实测与版本范围

- 11 套单元与 15 套浏览器回归完成；机制实验覆盖 55 个护盾条件、三个视口的 132 组组合和 33 组终局。
- 44 次不开火对照中，站定策略累计损失 149 点船体，可见预警移动策略为 80 点。这是固定条件的自动实验，不是所有路线公平性的证明。
- 11 只 Boss 已有生产渲染与实际声音录像；21 段 Web Audio 采样没有测得削波。源码真实 HTTP 检查覆盖三战机按键、模型、音频和语言。
- 收尾前代码 `0d4c64d` 完成 600 秒实时 RAF 运行：战斗时钟 511.638 秒，见到 9 Boss、击破 8 Boss，无报错。初始生命设为 12，结束剩 3；每 5 分钟强制 GC，结束 JS 堆约 12.13 MiB。它不代表新绘图代码的长时运行或自然通关。
- 最终材质收尾后另有 24 项像素边界、42 项亚像素虚空收缩、18 帧生产绘图检查，未出现运行或资源错误。最终三档性能数据与冻结 Game 的 HTTP 检查以随版交付报告为准，旧性能数据不冒充新版本测量。

最终性能检查为 1440×900、Chrome 157、i7-13700HX 电脑的四只代表 Boss × 三档画质，每案预热后测 10 秒、开启音频且不录屏。低/中/高画质的 RAF 帧间隔 p95 分别为 9.9–19.9 / 20.1–33.1 / 22.9–37.8 ms；高画质 CPU 帧提交 p95 为 4.6–7.0 ms。细节增加带来额外开销，不能把轮廓收尾前更低的帧时间作为最终值；CPU 提交耗时也不等于 GPU 完成耗时。

## 已知限制

水体和碎片仍是离线图集与二维材质几何，没有真正三维流体、全场体积模拟或物理破碎，也未整套重制机体模型与骨骼。配乐复用三阵营主题，并非 11 首新 Boss 主题。固定驾驶策略的自然流程止于第 10 关，尚无完整自然通关或人工耳机/音箱试听结论；低端、移动设备及更多浏览器仍需验证。本版不宣称达到商业 3A 等级或所有硬件稳定 60 fps。

冻结包的 Commit、Tag、ZIP SHA-256 与逐文件校验以随包 manifest 为准。独立复测须保持 Game 原样，分别记录自动实验、布置录像、键盘实玩与人工试听结果。
