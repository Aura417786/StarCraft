# Star Breaker Final Release Candidate · v23-rc1

这是在 v22 上修复独立验收问题的候选版本。保留十一只异形首领、三架战机、进化、战役、挑战与原有存档。公开试玩站点可能仍是旧版，请按独立测试包的 manifest 核对版本。

## 启动

解压完整 ZIP 后进入 `Game` 文件夹，用本地 HTTP 服务启动：

```powershell
python -m http.server 4182 --bind 127.0.0.1
```

保持此窗口打开，用电脑浏览器访问 [本地游戏](http://127.0.0.1:4182/)。推荐 1280×720 或更大的窗口。640×360 可操作，但战斗信息更紧凑。

也可双击 `Game/index.html` 离线启动兼容模式；由于浏览器的本地文件限制，此时不使用完整实时三维与动态水面。不要只复制单独的网页文件。

## 本轮变化

- **拆招后反击。** 丝结、镜像、电极、孢囊、神经中继与合体肢体被有效拆除后，会短暂显示金色反击窗口。同一招仅触发一次；其他仍在场的危险不会消失。
- **真正攻击弱点。** 骨冠和神经终局的完整护罩会有效阻挡对本体的蛮打。黄色大招按波命中实际覆盖的合法部件，蓝色大招追踪当前可攻击部件，并在其破坏后转向下一处。每发仍只结算原有的一包伤害。
- **三机操作收益。** 赤焰短点蓄力不再比完整蓄力更划算；曜金近距压制场按实际接触位置命中部件，并提示展开距离。苍电保持标记、连锁与机动节奏。
- **不再用隐藏倒计时锁血。** 保留入场和变形保护、单发与爆发上限；正常可攻击阶段的有效伤害不再被最低存活时间吞掉。半血破壳后的核心外露为 2.4 秒。
- **阅读与暂停。** Boss 入场构图收口；小窗口机库能完整显示开始按钮；HUD 装载信息与生命区分离。切走窗口或断开手柄会显示暂停，回来后需主动继续。
- **成绩与音频。** 关闭震动、减少动态不再改变新成绩类别，延长攻击预警仍计入辅助成绩；预警发声期间音乐会适当降低，随后恢复。

## 操作

| 按键 | 用途 |
| --- | --- |
| WASD / 方向键 | 飞行；主炮默认自动开火 |
| Shift | 聚焦 / 扩散姿态；三级翼炮有额外蓄力动作 |
| C | 赤焰蓄力，松开释放主炮 |
| Space | 当前战机的大招 |
| V | 护盾；贴近受击时机可完美格挡 |
| F | 已升级的僚机指令 |
| J | 关闭自动开火后的手动射击 |
| Esc | 暂停与继续 |

设置中可以改键。标准手柄支持左摇杆 / 方向键飞行，A / RT 手动射击，X 护盾，Y 大招，LT 蓄力，LB 姿态，RB 僚机，Start 暂停，B 返回。菜单用方向键选择、A 确认。实体手柄的兼容性和震动仍需按具体硬件验收。

## 存档与隐私

v23-rc1 沿用 v22 的 v2 档案格式，不重置战功、进化记录、徽章、外观或设置。历史辅助成绩保留原分类，不重新改写。新局中途打开延长预警，即使再关闭，该局仍属于辅助成绩。

数据保存在当前浏览器、当前网址的本地存储；更换端口、浏览器或本地文件位置可能看到另一份存档。不要通过清除网站数据升级。无法读取主档案时会尝试已有的本机备份。浏览器禁止存储时，仅当前会话能保留资料。游戏不上传战绩，没有云同步账号。

## 测试口径

发布材料区分固定场景、实时浏览器自动驾驶与人工试玩。自动驾驶使用正常初始生命和奖励、真实键盘事件，但可以读取战场状态，因此不能用其通关证明新手初见难度合适。耳机听感、实体手柄、人手完整战役与不看文字的首领识别仍需要独立体验验收；不将本次候选版宣传为已经达到 3A 商业品质。

可复现入口见 [测试说明](../tools/testkit/README.md)。本地工作台的 `AI_Development/Reports/Final_Release_Report.md` 和 `Final_Test_Report.md` 记录最终提交、ZIP、哈希、实测数据及限制。

本机暖场测试保持流畅，但首次开局仍记录到约 140 毫秒的输入峰值，低画质水技能也有一次约 163 毫秒的长帧。低配置设备尚未实测；这些限制保留在测试报告中。
