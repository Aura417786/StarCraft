我用 vibe coding 做了一款电脑浏览器横向射击小游戏，叫《星际突围 · Star Breaker》。想找一些愿意玩一局的人，看看这款游戏实际玩起来怎样。

试玩入口 → https://star-breaker-aura-261107.huafeihua560.chatgpt.site/

我负责提出想法、亲自试玩和描述问题，AI 协助实现代码、排查问题和制作素材。最初只做了移动、自动射击和计分，后面的改动主要来自实际试玩时发现的问题。

例如，后期子弹太密，就把弹道成长改成超过四条时晋级，将伤害集中到更高阶的能量弹。试玩中又发现，高阶弹道叠加聚焦和暴走后，普通敌机和首领都能在一轮里被清掉。我保留了开局的升级反馈，并调整了后期伤害，让厚甲目标和首领有时间施展招式，也让躲避和反击时机重新有用。进化可以展开翼炮、召来星隼僚机，或让护盾吸收敌弹并反击。编队和首领的追击会在第一轮过后再次锁定。最终合体会切换攻击方向，躲避时要同时考虑高度和前后位置。

我最想展示的三处体验是这些。

- 观察渊潮母体的海啸预警，沿青色潮沟穿过浪墙，再击碎它的胚卵。
- 射中能量球升级主炮，等敌弹贴近再开盾触发完美格挡，再接上速蓄大招。击败首领后可以三选一进化。
- 巨舰遮住星光，接着从机库派出编队。可以借漂出的残骸挡弹，也可以绕出去对准编队开火。

技术上采用原生 HTML、CSS、JavaScript、Canvas 2D、Three.js 和 Web Audio。场景用会翻滚的陨石、断舰和分层视差表现距离；原创分轨配乐在浏览器中随首领阶段混音。

这次项目也让我开始接触 Git。我经历了查看文件改动、本地提交，再把完整版本推送到 GitHub 的过程。项目仓库地址是 https://github.com/Aura417786/StarCraft 。源码访问范围以仓库当前设置为准。

游戏适合电脑浏览器和键盘。方向键 / WASD 移动，主炮自动开火，Shift 切换扩散与聚焦，空格释放战机大招，V 开护盾。

如果你愿意试玩，希望你告诉我三个具体时刻——第一次阵亡、觉得最爽，以及决定退出。性能异常或页面无法打开，也请附上浏览器、电脑环境和截图。反馈可以直接回帖，存活时间和得分截图也欢迎。
